---
control_id: DE-01
title: Dependency vulnerability monitoring
difficulty: easy
time_estimate: 15 minutes
docs_url: https://docs.ancilis.ai/cli/scan
evidence_needed:
  - Dependency manifest detected during scan
  - Vulnerable packages upgraded or added to an explicit ignore list with justification
fix_steps:
  - Run ancilis scan from the project root so dependency manifests are detected.
  - Upgrade vulnerable packages to the fixed versions reported by the scan.
  - Use scan.dependencies.ignore only for documented false positives or accepted risk.
code_example: |
  scan:
    dependencies:
      enabled: true
      severity_threshold: high
      ignore: []
---
Dependency evidence indicates vulnerable packages, missing manifest coverage, or
monitoring that is not configured for the project.

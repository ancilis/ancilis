# Ancilis Cover MCP

Ancilis Cover is a local stdio MCP server for AI coding assistants. It helps an assistant inspect an uninstrumented AI project, classify likely regulated data, recommend Ancilis setup, review explicit files or snippets, and generate an onboarding report.

Cover is read-only in this first iteration.

## Install

```bash
pip install ancilis
```

## MCP Host Configuration

Configure your MCP host to launch `ancilis-cover` locally:

```json
{
  "mcpServers": {
    "ancilis-cover": {
      "command": "ancilis-cover",
      "args": []
    }
  }
}
```

The server runs on the developer machine. Ancilis does not host this server.

## Tools

| Tool | Purpose |
|------|---------|
| `ancilis_inspect_project` | Detect project language, dependencies, frameworks, existing Ancilis config, and likely producers. |
| `ancilis_classify_project` | Map deterministic project signals to `my_agent_handles`, classifications, and overlays. |
| `ancilis_recommend_setup` | Return install commands, minimal `ancilis.yaml`, integration snippets, and validation commands. |
| `ancilis_review_code` | Review explicit files or snippets for sensitive-data patterns and tool surfaces. |
| `ancilis_onboarding_report` | Generate a short Markdown report with summary and next steps. |

## Privacy Guarantees

The first iteration is deterministic and local:

- No LLM calls.
- No MCP sampling.
- No network calls.
- No file writes.
- No reads outside the requested project root.
- Bounded directory traversal and bounded file reads.
- Redacted samples for sensitive-data findings.

## Typical Flow

1. Call `ancilis_inspect_project` for the repo root.
2. Call `ancilis_classify_project` with the inspection signals and optional project description.
3. Call `ancilis_recommend_setup` to get install commands, config, snippets, and validation commands.
4. Optionally call `ancilis_review_code` on specific files before editing.
5. Call `ancilis_onboarding_report` for a concise summary the coding assistant can act on.

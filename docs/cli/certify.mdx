## Overview

`ancilis certify` evaluates the evidence in your local store against the controls required by a specific framework or certification target (SOC 2, HIPAA, PCI, AIUC-1, or the EU AI Act) and reports per-control coverage. It is a read-only command — it never writes certification artifacts.

```bash
ancilis certify --target <framework> [OPTIONS]
```

<Note>
`certify` always runs in dry-run mode. It computes coverage and prints a report but never writes certification artifacts, regardless of the `--dry-run` flag. JSON output always reports `"dry_run": true`.
</Note>

## Flags

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--target` | choice | required | Framework or certification target to evaluate: `soc2`, `hipaa`, `pci`, `aiuc1`, or `eu_ai_act` |
| `--dry-run` | flag | always on | Compute coverage without writing certification artifacts. Accepted for compatibility; the command is already dry-run unconditionally |
| `--format` | choice | `table` | Output format: `table` or `json` |
| `--config` | string | auto-detect | Path to `ancilis.yaml` |
| `--db` | string | per-agent, per-cwd path | Path to evidence database. When omitted, the store derives `~/.ancilis/<agent-name>-<8-char-cwd-hash>/evidence.duckdb` (the file is always named `evidence.duckdb`) |

## Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Coverage report produced successfully |
| `1` | Config could not be loaded (no `ancilis.yaml` found and no `--config`/`--db` provided, or an invalid config) |

## Coverage Statuses

Each control in the report carries a `coverage_status` and an `action_required` hint:

| `coverage_status` | Meaning | `action_required` |
|-------------------|---------|-------------------|
| `covered` | The control is satisfied by collected or attestation evidence | `—` |
| `gap` | No passing evidence — the control is unmet | `remediate` |
| `policy_gated` | The control is not runtime-active under the explicit/certification policy gate | `enable in policy` |
| `attestation_required` | A manual attestation is needed for this control | `ancilis attest <control_id>` |
| `attestation_stale` | A prior attestation has expired and must be renewed | `ancilis attest <control_id>` |
| `attestation_incomplete` | An attestation exists but does not cover all required agents/scope | `ancilis attest <control_id>` |

**Evaluate the EU AI Act target with an explicit config and database**
```bash

```

**Other supported targets**
```bash
ancilis certify --target pci
ancilis certify --target aiuc1
```

## Common Errors

| Error | Fix |
|-------|-----|
| `No ancilis.yaml found and no config provided` | Run `ancilis init`, or pass `--config path/to/ancilis.yaml` |
| `Error: <validation message>` (invalid config) | Fix `ancilis.yaml`, or pass a valid `--config` path |
| Controls show `gap` | Run your agent with Ancilis middleware active to collect evidence, then re-run `certify` |
| Controls show `attestation_required` | Complete the manual attestation for the listed control |

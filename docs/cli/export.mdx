## Overview

`ancilis export` reads evidence records from the local DuckDB store and emits them as NDJSON (default) or CSV. Records print to stdout unless you pass `--output`, which writes them to a file instead. This is a read-only operation — it never mutates or deletes evidence.

```bash
ancilis export [OPTIONS]
```

## Flags

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--format` | `ndjson` \| `csv` | `ndjson` | Output format |
| `--since` | string | all records | Only include records at or after this ISO-8601 timestamp |
| `--session` | string | all sessions | Only include records from this session ID |
| `--config` | string | auto-detect | Path to `ancilis.yaml` |
| `--db` | string | per-agent, per-cwd path (see below) | Path to evidence database |
| `--output`, `-o` | string | stdout | Output file path |

<Note>
  When `--db` is omitted, the evidence store derives a per-agent, per-cwd path: `~/.ancilis/<agent-name>-<8-char-cwd-hash>/evidence.duckdb`. The cwd hash disambiguates agents with the same name across different projects; the database file is always named `evidence.duckdb`.
</Note>

<Note>
  When `--db` points to an existing database, `--config` is optional — if no config is found, `export` falls back to a synthetic `evidence-export` agent so you can dump records from any database file directly.
</Note>

## Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Export succeeded (including when zero records match) |
| `1` | Database file passed via `--db` does not exist, or config is missing/invalid and no `--db` was supplied |

**Export as CSV to a file**
```bash
ancilis export --format csv --output evidence.csv
```

```
Export written to evidence.csv
```

The CSV starts with a header row carrying these columns in order:

```
record_id,evaluation_id,timestamp,agent_id,session_id,source_type,tool_name,decision,mode,control_results,active_overlays,data_classifications,active_certifications,record_hash,previous_hash,total_duration_ms,output_summary,tenant_id,detected_data_types,sdk_version,framework_version,classification_context
```

Each subsequent row is one evidence record. The `control_results` column holds the full JSON array as a single quoted CSV field (with `""` escaping), so a row can be very wide; list and dict columns such as `active_overlays`, `data_classifications`, and `classification_context` are likewise serialized as JSON.

**Export records from a specific session**
```bash
ancilis export --session sess_20260606_abc123 --output session.ndjson
```

**Export records since a timestamp**
```bash
ancilis export --since 2026-06-01T00:00:00Z
```

**Export directly from a database file (no config)**
```bash
ancilis export --db /path/to/evidence.duckdb --format csv -o dump.csv
```

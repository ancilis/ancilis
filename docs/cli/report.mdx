## Overview

`ancilis report` generates a formatted compliance posture report from collected evidence. Supports human-readable terminal output, markdown, PDF, CSV, and machine-readable NDJSON formats for audit export.

```bash
ancilis report [OPTIONS]
ancilis report generate [OPTIONS]  # explicit subcommand (identical behavior)
```

## Flags

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--format` | choice | `terminal` | Output format: `terminal`, `markdown`, `pdf`, `aiuc1-readiness`, `ndjson`, `csv`, `oscal` |
| `--period` | string | `30d` | Reporting period — e.g. `7d`, `30d`, `90d`, `365d` |
| `--output`, `-o` | path | stdout | Output file path (defaults to `ancilis-report.pdf` for `pdf`) |
| `--session` | string | latest | Scope to a specific session ID |
| `--latest` / `--all` | flag | `--latest` | Use latest session (default) or all sessions |
| `--config` | string | auto-detect | Path to `ancilis.yaml` |
| `--db` | string | default | Path to evidence database |

## Output Formats

| Format | Description | Best For |
|--------|-------------|----------|
| `terminal` | Color-coded table for human review | Development, quick checks |
| `markdown` | GitHub-flavored markdown | PR comments, wiki uploads |
| `pdf` | PDF via pandoc/xelatex (falls back to markdown if unavailable) | Formal audit packages |
| `aiuc1-readiness` | Markdown formatted for AIUC-1 readiness reviews | Certification prep |
| `ndjson` | One evidence record per line | Log pipelines, SIEM ingestion |
| `csv` | Spreadsheet-compatible evidence export | Audit spreadsheets |
| `oscal` | OSCAL Assessment Results JSON (AKSI → NIST SP 800-53 Rev 5) | GRC tooling, NIST workflows |

## Examples

**Terminal report (default)**
```bash
ancilis report
```

```
Ancilis Posture Report — my-agent
Period: 2026-05-08 to 2026-06-07
Mode: audit
Posture: HEALTHY (1/39 controls passing)
Evaluations: 15 total | 0 blocked | 15 allowed
Active overlays: Financial Services (GLBA, SOX, DORA), SOC 2 Type II
Active certifications: none
Evidence chain: ✓ legacy-unverified (set ANCILIS_CHAIN_KEY) (15 records)

Baseline Controls:
  ✓ 1 controls passing (full detail preserved in markdown)
Tools evaluated: dependency-scanner

Compliance Matrix:
  Control | Financial Services (GLBA, SOX, DORA) | SOC 2 Type II
  DE-01   | ✓                                    | ✓
  DE-02   | -                                    | -
  ...
```

**Markdown report to file**
```bash
ancilis report --format markdown --output report.md --period 7d
```

**PDF report for auditors**
```bash
ancilis report --format pdf --output ancilis-report-q1.pdf --period 90d
```

**NDJSON export to stdout**
```bash
ancilis report --format ndjson --period 30d | jq '.control_results[].control_id'
```

**CSV export**
```bash
ancilis report --format csv --output evidence-export.csv --all
```

**Scope report to a specific session**
```bash
ancilis report --session sess_20260412_abc123 --format markdown
```

**30-day readiness report**
```bash
ancilis report --format aiuc1-readiness --period 30d --output readiness.md
```

## Common Errors

| Error | Fix |
|-------|-----|
| `ancilis.yaml not found` | Pass `--config path/to/ancilis.yaml` or run from project root |
| `No evidence found` | Run your agent with Ancilis middleware to collect evidence |
| PDF falls back to markdown | Install pandoc and a LaTeX engine (xelatex) so `pandoc --pdf-engine=xelatex` is available |

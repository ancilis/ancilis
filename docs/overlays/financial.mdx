## Overview

The `glba` overlay is designed for AI agents that handle customer financial data, process transaction records, support financial reporting workflows, or operate inside financial institutions subject to US or EU financial services regulation.

It packages evidence simultaneously for three frameworks:

| Framework | Full Name | Scope |
|-----------|-----------|-------|
| **GLBA** | Gramm-Leach-Bliley Act Safeguards Rule (16 CFR 314) | US financial institutions handling customer NPI |
| **SOX** | Sarbanes-Oxley Act §302 / §404 | Public company internal controls over financial reporting |
| **DORA** | EU Digital Operational Resilience Act | EU financial entities and ICT service providers |

---

## Activation

**Explicit in `ancilis.yaml`:**
```yaml
compliance:
  overlays:
    - glba
```

**Automatic trigger** — activates when your agent declares data classifications matching financial data types:
```yaml
# ancilis.yaml
my_agent_handles:
  - financial-data
```

Confirm activation via `ancilis status`:
```
Financial overlay: active — triggered by financial data declaration
```

## Evidence Requirements

The overlay adds specific evidence requirements to each control evaluation:

### PR-01 — Identity & Authorization
- Information security program documented and approved by senior leadership (GLBA 314.4(a))
- Qualified individual designated to oversee the information security program
- Annual written report to the board on the information security program (GLBA 314.4(i))
- SOX §302 CEO/CFO certifications address information security

### PR-04 — Data Exposure Prevention
- Encryption of customer financial information in transit and at rest (GLBA 314.4(e))
- No NPI (non-public personal information) transmitted without authorization
- SOX material financial disclosure controls active

### PR-05 — Audit Trail
- Audit and testing program covering the information security program (GLBA 314.4(h))
- SOX §404 management assessment of internal controls documented
- ICT-related incident logging per DORA Art.17

## Example `ancilis.yaml` Configuration

```yaml
agent:
  name: financial-reporting-agent
  description: "Agent for automated financial report generation"

security:
  mode: enforce   # enforce mode recommended for financial services

compliance:
  overlays:
    - glba
  evidence:
    retention_days: 2555  # 7 years for SOX §802 compliance

scan:
  dependencies:
    enabled: true
    severity_threshold: high
```

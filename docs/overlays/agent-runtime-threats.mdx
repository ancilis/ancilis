## Overview

The `agent-runtime-threats` overlay packages AKSI control wiring for runtime threats that apply to AI agents. It exists to resolve a dangling control-to-overlay reference: it connects the 39 AKSI controls that reference `agent-runtime-threats` to the overlay, without asserting any requirement-ID crosswalk. No framework references or evidence requirements are defined yet — the overlay carries control wiring only.

**Use this overlay when your agent:**
- Handles data classified as `DC-AI` (AI-classified data)
- Needs the `agent-runtime-threats` controls wired into its compliance configuration
- Is being prepared for a future runtime-threat evidence mapping (scaffold stage)

---

## Activation

```yaml
# ancilis.yaml
compliance:
  overlays:
    - agent-runtime-threats
```

**Data classification trigger** — because this overlay's `trigger_type` is `data_classification`, it also auto-activates when your agent declares handling of the relevant data class (`DC-AI`) via `my_agent_handles`:
```yaml
my_agent_handles:
  - DC-AI
```
See [Data Classification](/data-classification) for how classification codes map to overlays.

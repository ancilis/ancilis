## Overview

The Cloud Security Alliance (CSA) Cloud Controls Matrix (CCM) is a cybersecurity control framework for cloud computing. The `csa_ccm` overlay packages the AKSI controls that reference this framework so they can be activated together for an agent.

<Warning>
This overlay is a **scaffold mapping** and is not yet backed by runtime evidence. It was created to resolve a dangling control-to-overlay reference: it wires the controls that reference `csa_ccm` but asserts **no** framework requirement mappings (`framework_mapping` is empty, and every control's `framework_reference` and `evidence_requirements` are unset). Treat coverage as **indicative only** — populate from an authoritative source before relying on it for any production compliance assertion.
</Warning>

**Use this overlay when your agent:**
- Operates in a cloud environment governed by the CSA Cloud Controls Matrix
- Declares that it handles AI data classified as `DC-AI`
- Needs the controls referencing `csa_ccm` activated as a group
- Is establishing scaffold coverage ahead of an authoritative framework crosswalk

---

## Activation

Activate explicitly by adding the overlay to your `ancilis.yaml`:

```yaml
# ancilis.yaml
compliance:
  overlays:
    - csa_ccm
```

**Data classification trigger** — because this overlay's `trigger_type` is `data_classification`, it also auto-activates when your agent declares that it handles the relevant data classification (`DC-AI`) via `my_agent_handles`. See [Data Classification](/data-classification) for how to declare the `DC-AI` code.

## Overview

The NIST Privacy Framework v1.0 (Jan 16, 2020) is a voluntary US enterprise privacy-risk-management tool organized as 5 Functions (Identify-P, Govern-P, Control-P, Communicate-P, Protect-P), 18 Categories, and 100 Subcategories addressing privacy risks arising from data processing. Version 1.1 was released as an Initial Public Draft on April 14, 2025 (comment period closed June 13, 2025) and remained in draft as of June 2026, so v1.0 is the current finalized version. Most subcategories are organization-wide privacy-program outcomes; the AKSI mappings cover only the agent-responsibility boundary.

The `nist_privacy_framework` overlay packages AKSI control evidence against the framework's Subcategories, mapping each AKSI control to the relevant Privacy Framework subcategory references (e.g., `PR.AC-P1`, `CT.DM-P8`, `GV.MT-P5`).

<Warning>
This overlay is a scaffold mapping not yet backed by runtime evidence. Every control's evidence requirements are currently empty and the underlying crosswalk is marked REVIEW-FIRST (most mappings are partial and many are unverified). Treat the coverage shown below as indicative, not production-asserted.
</Warning>

**Use this overlay when your agent:**
- Operates within an enterprise applying the NIST Privacy Framework for privacy risk management
- Processes data that creates privacy risks for individuals (PII, NPI, PHI, minors' data, biometric, or education records)
- Needs to demonstrate agent-boundary coverage of Identify-P, Govern-P, Control-P, Communicate-P, and Protect-P outcomes
- Supports a privacy program that maps technical controls to Privacy Framework Subcategories

## Activation

```yaml
# ancilis.yaml
compliance:
  overlays:
    - nist_privacy_framework
```

**Data classification trigger** — because this overlay's trigger type is `data_classification`, it also auto-activates when your agent declares (via `my_agent_handles`) that it handles data in any of the relevant classifications: `DC-PII`, `DC-NPI`, `DC-PHI`, `DC-MINOR`, `DC-BIO`, or `DC-EDU`. See [Data Classification](/data-classification) for declaring handled data classes.

## Retention & Jurisdiction

**Jurisdiction:** United States (NIST voluntary framework; used globally, sector-agnostic).

The NIST Privacy Framework is a voluntary risk-management tool and does not itself prescribe a fixed evidence-retention period; this overlay declares no minimum retention day-count. Set evidence retention according to your organization's privacy program and any other binding overlays in effect.

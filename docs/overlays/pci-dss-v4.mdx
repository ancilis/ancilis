## Overview

The `pci-dss-v4` overlay maps AKSI control evidence to the Payment Card Industry Data Security Standard (PCI-DSS) v4.0. PCI-DSS applies to any system that stores, processes, or transmits cardholder data or sensitive authentication data. This overlay packages the AKSI control evidence required to demonstrate coverage of the PCI-DSS v4.0 requirements that are in scope for an agent SDK — identity (Req 8), access control (Req 7), data protection (Req 3–4), logging (Req 10), and monitoring (Req 10.4) — and applies strict evidence thresholds where the standard mandates them.

**Use this overlay when your agent:**
- Stores, processes, or transmits cardholder data (CHD)
- Handles sensitive authentication data such as PAN, track data, CVV, or PIN data
- Operates within a cardholder data environment (CDE)
- Supports a business pursuing or maintaining PCI-DSS v4.0 attestation (SAQ or ROC)

---

## Activation

```yaml
# ancilis.yaml
compliance:
  overlays:
    - pci-dss-v4
```

**Data classification trigger** — this overlay also auto-activates when your agent declares that it handles cardholder data, classified as `DC-CHD`, via `my_agent_handles`. See [Data Classification](/data-classification) for how to declare the data your agent handles.

```yaml
my_agent_handles:
  - DC-CHD
```

## Retention & Jurisdiction

- **Jurisdiction:** global
- **Evidence retention minimum:** 365 days

PCI-DSS v4.0 applies globally to any entity that stores, processes, or transmits cardholder data, regardless of location. This overlay enforces a minimum evidence retention of 365 days.

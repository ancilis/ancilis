## Overview

The NIST AI Risk Management Framework (AI RMF v1.0, January 2023) is a voluntary framework for managing risks across the AI lifecycle, organized into four core functions — **GOVERN**, **MAP**, **MEASURE**, and **MANAGE**. It applies to all AI system deployments regardless of data classification.

The `nist-ai-rmf` overlay packages AKSI control evidence against these four functions. It maps each AKSI control to the relevant AI RMF subcategories so that an agent deployment can demonstrate AI trustworthiness alignment. The overlay is always-on: it activates for any AI agent deployment because the AI RMF applies to all AI systems. Jurisdiction is **US (voluntary framework, federal procurement increasingly expected)**.

**Use this overlay when your agent:**
- Is any AI agent deployment for which you need to demonstrate NIST AI RMF alignment
- Supports federal procurement or contracts increasingly requiring AI RMF alignment documentation
- Undergoes structured AI trustworthiness assessment across the Govern, Map, Measure, and Manage functions
- Relies on third-party model infrastructure where upstream AI developers/providers share accountability

---

## Activation

The overlay is enabled explicitly in your project configuration:

```yaml
# ancilis.yaml
compliance:
  overlays:
    - nist-ai-rmf
```

This overlay is **always-on** (`trigger_type: always_on`) — it applies to any AI agent deployment regardless of the data classes the agent declares. The framework recognizes data classes `DC-AI`, `DC-GEN`, `DC-PII`, `DC-PHI`, `DC-FIN`, `DC-FCI`, `DC-GOV`, and `DC-CUI`; see [Data Classification](/data-classification) for how these are declared.

## Overview

ISO/IEC 42001:2023 is the AI Management System (AIMS) standard — the ISO 27001 equivalent for AI. It provides requirements for establishing, implementing, maintaining, and continually improving an AI management system for the responsible development and use of AI. Its structure spans Clauses 4–10 (management system requirements) plus Annex A (organizational controls).

The `iso-42001` overlay packages AKSI control evidence against the ISO/IEC 42001 AIMS requirements. It maps each AKSI control to the relevant ISO 42001 Clause and Annex A references, so that agent runtime evidence can be presented alongside an organization's AIMS documentation.

**Use this overlay when your agent:**
- Operates within an organization establishing or maintaining an AI management system (AIMS)
- Declares handling of AI training data (`DC-AI`)
- Is in scope for ISO/IEC 42001 certification or surveillance audits
- Needs to demonstrate responsible AI development and use evidence to management or an accredited certification body

---

## Activation

```yaml
# ancilis.yaml
compliance:
  overlays:
    - iso-42001
```

**Data classification trigger** — because this overlay's `trigger_type` is `data_classification`, it also auto-activates when your agent declares handling of the relevant data class (`DC-AI`) via `my_agent_handles`. See [Data Classification](/data-classification) for the declaration format.

## Retention & Jurisdiction

- **Jurisdiction:** global
- **Evidence retention minimum:** 1095 days

These values are set by the overlay definition and govern how long control evidence must be retained to support ISO/IEC 42001 AIMS audits.

## Overview

NIST SP 800-218, the Secure Software Development Framework (SSDF) v1.1, is a voluntary, outcome-based secure-software-development framework of 19 practices / 42 tasks across four groups — PO (Prepare the Organization), PS (Protect the Software), PW (Produce Well-Secured Software), and RV (Respond to Vulnerabilities) — referenced by EO 14028 and the OMB self-attestation regime. SSDF is fundamentally an organization-and-SDLC process framework, so the agent-responsibility boundary is narrow.

The `nist_sp_800_218_ssdf` overlay packages Ancilis control evidence against the SSDF practices and tasks, mapping each Ancilis control to the SSDF tasks (PO/PS/PW/RV task IDs) it speaks to.

<Warning>
This overlay is an indicative crosswalk mapping that is not yet backed by runtime evidence. Every control's evidence requirements are still unspecified, and most underlying mappings are marked partial with many unverified (REVIEW-FIRST, not production-asserted). Treat coverage as indicative, not as an authoritative SSDF attestation.
</Warning>

**Use this overlay when your agent:**
- Is part of a software product or service that must attest to SSDF practices under EO 14028 / OMB M-22-18 / M-23-16
- Produces, builds, or releases software components where provenance and integrity matter
- Operates within a FedRAMP or federal supply-chain context that references SSDF
- Needs to evidence vulnerability response, root-cause analysis, and secure-development hygiene for an AI agent

## Activation

```yaml
# ancilis.yaml
compliance:
  overlays:
    - nist_sp_800_218_ssdf
```

This overlay is a certification-triggered overlay (`trigger_type: certification`) and is activated explicitly by listing it under `compliance.overlays`.

## Retention & Jurisdiction

**Jurisdiction:** United States (NIST; referenced by EO 14028 / OMB M-22-18 / M-23-16 attestation and FedRAMP; voluntary framework adopted globally).

**Evidence retention:** This overlay does not specify a minimum evidence retention period. Set retention according to the requirements of the program or attestation regime that references SSDF for your deployment.

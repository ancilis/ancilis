## Configuration

### `loadConfig()`

Load and validate `ancilis.yaml` into a `ResolvedConfig` object.

```typescript
import { loadConfig } from "ancilis";

const config = await loadConfig();                          // auto-detect
const config = await loadConfig({ path: "ancilis.yaml" }); // explicit path
```

**`LoadConfigOptions`**

```typescript
interface LoadConfigOptions {
  path?: string;   // explicit path to ancilis.yaml
  raw?: object;    // inline config object (testing)
}
```

### `ancilis.yaml` Schema

Same schema as the Python SDK — see the [Python SDK reference](/sdk/python#configuration) for the full schema. TypeScript `loadConfig()` reads the same `ancilis.yaml` file format.

## Producers

### `ToolActionProducer` — JavaScript functions

```typescript
import { ToolActionProducer, wrapTool, tool, loadConfig } from "ancilis";
import { Engine } from "ancilis";
import { EvidenceStore } from "ancilis";

const config = await loadConfig();
const engine = new Engine(config);
const store = new EvidenceStore(config);
const producer = new ToolActionProducer(config, engine, { evidenceStore: store });

// Decorator-style via tool()
const queryDatabase = tool(producer)(
  async (sql: string, database: string): Promise<Record<string, unknown>> => {
    return await db.execute(sql);
  },
  { toolName: "query_database" }
);

const result = await queryDatabase("SELECT * FROM users LIMIT 10", "reports");
```

**`wrapTool()`**

```typescript
import { wrapTool } from "ancilis";

const wrapped = wrapTool(originalFn, producer, { toolName: "shell_execute" });
const result = await wrapped("ls", "-la");
```

**`evaluateAndExecute()`**

```typescript
import { evaluateAndExecute } from "ancilis";

const result = await evaluateAndExecute({
  fn: executeShellCommand,
  producer,
  args: ["ls", "-la"],
  toolName: "shell_execute",
});
// result.blocked: boolean
// result.evaluation: EvaluationResult
```

**Handling blocked actions**

```typescript
import { BlockedActionError } from "ancilis";

try {
  await queryDatabase(sql, db);
} catch (e) {
  if (e instanceof BlockedActionError) {
    console.error(e.message);
    // "Ancilis [blocked]: Action 'query_database' blocked — scope violation."
  }
}
```

### `HTTPActionProducer` — HTTP/REST calls

```typescript
import { HTTPActionProducer } from "ancilis";
import type { HTTPObservation } from "ancilis";

const producer = new HTTPActionProducer(config, engine, { evidenceStore: store });

const observation: HTTPObservation = {
  method: "POST",
  url: "https://api.example.com/transfer",
  headers: { Authorization: "Bearer ..." },
  body: { amount: 1000, to: "acct_123" },
};
const result = await producer.observe(observation);
```

### `MCPActionProducer` — MCP tool calls

```typescript
import { MCPActionProducer, AncilisMiddleware } from "ancilis";
import type { McpClientLike } from "ancilis";

// Middleware approach (recommended)
const middleware = new AncilisMiddleware(config, { evidenceStore: store });

// Direct MCP producer
const mcpProducer = new MCPActionProducer(config, engine, {
  mcpClient: yourMcpClient,
  evidenceStore: store,
});
```

### `CLIActionProducer` — subprocess commands

```typescript
import { CLIActionProducer } from "ancilis";
import type { CLIInvocation } from "ancilis";

const producer = new CLIActionProducer(config, engine, { evidenceStore: store });

const invocation: CLIInvocation = {
  command: ["git", "push", "origin", "main"],
  cwd: "/workspace/project",
};
const result = await producer.observe(invocation);
// result.blocked: boolean
```

### `AncilisMiddleware` — MCP server middleware

```typescript
import { AncilisMiddleware } from "ancilis";
import type { AncilisMiddlewareOptions } from "ancilis";

const options: AncilisMiddlewareOptions = {
  evidenceStore: store,
  mode: "audit",  // override ancilis.yaml mode
};
const middleware = new AncilisMiddleware(config, options);

// Attach to your MCP server
server.use(middleware.handler());
```

### LLM SDK producers

Direct LLM provider producers wrap the SDK call surface. Same shape as `HTTPActionProducer` (observe-first, optional enforce, `wrapCreate()` helper). Duck-typed against the upstream SDK — no hard import.

```typescript
import Anthropic from "@anthropic-ai/sdk";
import { AnthropicActionProducer } from "ancilis";

const producer = new AnthropicActionProducer(config, engine, undefined, store);
const client = new Anthropic();

const wrapped = producer.wrapCreate(
  (kwargs) => client.messages.create(kwargs as Anthropic.Messages.MessageCreateParams),
  "support-bot",
);

const result = await wrapped({
  model: "claude-sonnet-4-6",
  messages: [{ role: "user", content: "..." }],
  max_tokens: 1024,
});
// result.response is the SDK response; result.evaluation is the policy decision
```

Available subclasses:
- `AnthropicActionProducer`, `OpenAIActionProducer` (covers both `chat.completions.create` and `responses.create`), `GeminiActionProducer`
- `MistralActionProducer`, `CohereActionProducer`, `XAIActionProducer`
- `GroqActionProducer`, `TogetherActionProducer`, `FireworksActionProducer`, `DeepSeekActionProducer` (OpenAI-compatible inference platforms)

Tool name format: `llm:{provider}:{model}`.

### Agent framework producers

| Producer | Framework | Wiring |
|----------|-----------|--------|
| `LangChainCallbackHandler` | LangChain.js / LangGraph | Pass into any Runnable/Chain via `callbacks=[handler]` |
| `CrewAIActionProducer` | CrewAI | `stepCallback()` / `taskCallback()` / `crewCallback()` factories |
| `AutoGenActionProducer` | AutoGen / AG2 | `attach(agent)` auto-wires `process_message_before_send` + `process_last_received_message` hooks |
| `SemanticKernelActionProducer` | Microsoft Semantic Kernel | `functionInvocationFilter()` / `promptRenderingFilter()` / `autoFunctionInvocationFilter()` factories |

```typescript
import { LangChainActionProducer, LangChainCallbackHandler } from "ancilis";

const producer = new LangChainActionProducer(config, engine, undefined, store);
const handler = new LangChainCallbackHandler(producer);

// Drop into any LangChain Runnable
const llm = new ChatAnthropic({ callbacks: [handler] });
```

### Auto-detection

`autoRegister(config, engine)` instantiates one producer per upstream npm package detected in the current environment via `createRequire(import.meta.url).resolve()` — no side effects.

```typescript
import { autoRegister, detectInstalledSdks, installedProviderSlugs } from "ancilis";

const producers = autoRegister(config, engine);
// producers = { anthropic: AnthropicActionProducer, openai: OpenAIActionProducer, langchain: ... }

// Diagnostics:
detectInstalledSdks();    // { anthropic: true, openai: false, langchain: true, ... }
installedProviderSlugs(); // ["anthropic", "langchain"]

// Filters:
autoRegister(config, engine, { include: ["anthropic", "openai"] });
autoRegister(config, engine, { exclude: ["deepseek"] });
```

The detector table covers `@anthropic-ai/sdk`, `openai`, `@google/genai` / `@google/generative-ai`, `@mistralai/mistralai`, `cohere-ai`, `groq-sdk`, `together-ai`, `fireworks-ai`, `@aws-sdk/client-bedrock-runtime` / `aws-sdk`, `@langchain/core` / `langchain`, `crewai`, `autogen`, and `@semantic-kernel/typescript` / `@microsoft/semantic-kernel`.

## Evidence Store

### `EvidenceStore`

```typescript
import { EvidenceStore, loadConfig } from "ancilis";

const config = await loadConfig();
const store = new EvidenceStore(config);
// Custom path:
const store = new EvidenceStore(config, { dbPath: "/custom/evidence.duckdb" });
```

**Key methods:**

```typescript
// Store an evaluation result
await store.store(evaluationResult, { toolName: "my_tool" });

// Get summary statistics
const summary = await store.getSummary({
  since: "2026-04-01T00:00:00Z",
  sessionId: "sess_abc",
});
// { totalEvaluations: 42, controlPassRates: {...}, decisions: {...} }

// Get individual records
const records = await store.getRecords({ since: ..., sessionId: ..., limit: 100 });

// Session management
const sessionId = await store.latestSessionId();
const sessions = await store.listSessions();

// Reset (clears all evidence, restarts hash chain)
const count = await store.reset();

// Always close
await store.close();
```

### Hash Chain

```typescript
import { GENESIS_SEED, canonicalPayload, computeHash } from "ancilis";

// Verify integrity
const summary = await store.getSummary();
const chainValid: boolean = summary.chainValid;
```

```typescript
import type { EvidenceRecord } from "ancilis";

const record: EvidenceRecord = {
```

```typescript
const config = await loadConfig();
```

## Error Types

| Class | When Thrown |
|-------|-------------|
| `BlockedActionError` | Tool call blocked in `enforce` mode |
| `ConfigError` | `ancilis.yaml` invalid or not found |
| `OverlayNotFoundError` | Overlay ID not recognized |
| `StorageError` | DuckDB I/O error |
| `AuthError` | Platform API authentication failure |

```typescript
import {
  BlockedActionError,
  ConfigError,
  OverlayNotFoundError,
  StorageError,
  AncilisError,
} from "ancilis";
```

## Side-by-Side Examples

<CodeGroup>
```python Python
from ancilis import load_config, ToolActionProducer, tool, EvidenceStore
from ancilis.engine.engine import Engine

config = load_config()
engine = Engine(config)
store = EvidenceStore(config)
producer = ToolActionProducer(config, engine, evidence_store=store)

@tool(producer)
def send_email(to: str, subject: str, body: str) -> bool:
    return email_client.send(to, subject, body)

result = send_email("user@example.com", "Report", "See attached.")
```

```typescript TypeScript
import { loadConfig, ToolActionProducer, tool, EvidenceStore } from "ancilis";
import { Engine } from "ancilis";

const config = await loadConfig();
const engine = new Engine(config);
const store = new EvidenceStore(config);
const producer = new ToolActionProducer(config, engine, { evidenceStore: store });

const sendEmail = tool(producer)(
  async (to: string, subject: string, body: string): Promise<boolean> => {
    return await emailClient.send(to, subject, body);
  },
  { toolName: "send_email" }
);

const result = await sendEmail("user@example.com", "Report", "See attached.");
```

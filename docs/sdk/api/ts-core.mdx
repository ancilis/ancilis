The core of the TypeScript SDK (the `ancilis` package). This page covers the ergonomic [`Ancilis`](#ancilis) facade, configuration loading, the decision [`Engine`](#engine) and [`ToolRegistry`](#toolregistry), the [`AncilisMiddleware`](#ancilismiddleware) MCP wrapper, the [`EvidenceStore`](#evidencestore) and its hash chain, and the structured `Ancilis*Error`/`AncilisWarning` types.

Every symbol below is exported from the top-level `ancilis` entry point. Signatures are copied verbatim from the compiled `.d.ts` declarations. Symbols re-exported with `export type` are type-only (interfaces, type aliases) and are marked as such; the rest are runtime value exports (classes, functions, constants).

```typescript
import {
  Ancilis,
  loadConfig,
  formatResolvedConfig,
  Engine,
  ToolRegistry,
  ToolStatus,
  DE04IntegrityEvaluator,
  AncilisMiddleware,
  BlockedToolCallError,
  scanResponse,
  EvidenceStore,
  GENESIS_SEED,
  canonicalPayload,
  computeHash,
  AncilisError,
} from "ancilis";
```

## Facade

### Ancilis

**Kind:** class &middot; **Module:** `ancilis/facade`

Ergonomic SDK facade for common runtime enforcement flows. It bundles a resolved [`config`](#resolvedconfig), an [`Engine`](#engine), a [`ToolRegistry`](#toolregistry), an [`EvidenceStore`](#evidencestore), and a `ToolActionProducer` into a single object. The constructor is private; build instances with the static [`load`](#ancilis-load) method.

```typescript
declare class Ancilis {
    readonly config: ResolvedConfig;
    readonly engine: Engine;
    readonly registry: ToolRegistry;
    readonly evidenceStore: EvidenceStore;
    readonly toolProducer: ToolActionProducer;
    private constructor();
    static load(options?: AncilisLoadOptions): Ancilis;
    tool<Args extends unknown[], Return>(fn: FacadeToolFn<Args, Return>, options?: AncilisToolOptions): AncilisToolRun<Args, Return>;
}
```

<a id="ancilis-load" />
- `static load(options?: AncilisLoadOptions): Ancilis` — construct an `Ancilis` facade, loading and resolving configuration and wiring up the engine, registry, and evidence store. Accepts [`AncilisLoadOptions`](#ancilisloadoptions) to override any of the wired components.
- `tool<Args, Return>(fn, options?): AncilisToolRun<Args, Return>` — wrap a plain function as a policy-enforced tool. Returns an [`AncilisToolRun`](#ancilistoolrun) whose `call` evaluates and (if allowed) invokes the function, and whose `evaluate` returns the `[Action, EvaluationResult]` pair without invoking it.

```typescript
import { Ancilis } from "ancilis";

const ancilis = Ancilis.load({ raw: { agent: { name: "ancilis-agent" } } });

const search = ancilis.tool(
  async (query: string) => fetchResults(query),
  { toolName: "web_search" },
);

const results = await search.call("ancilis");
```

## Configuration

### loadConfig

**Kind:** function &middot; **Module:** `ancilis/config`

Load and resolve an Ancilis configuration. Pass `path` to read an `ancilis.yaml` file, or `raw` to supply an in-memory config object. If neither is given, a [`ConfigError`](#configerror) is thrown. Returns a [`ResolvedConfig`](#resolvedconfig) with all controls, overlays, and classifications resolved.

```typescript
declare function loadConfig(options?: LoadConfigOptions): ResolvedConfig;
```

```typescript
import { loadConfig } from "ancilis";

// From a file
const config = loadConfig({ path: "ancilis.yaml" });

// From an in-memory object (no file required)
const inline = loadConfig({ raw: { agent: { name: "ancilis-agent" } } });
```

## Engine

### Engine

**Kind:** class &middot; **Module:** `ancilis/engine`

Decision engine — orchestrates control evaluation. Built from a [`ResolvedConfig`](#resolvedconfig) (and optionally a [`ToolRegistry`](#toolregistry), rate tracker, baseline window, and evidence-store adapter), it evaluates an [`Action`](#action) and returns an [`EvaluationResult`](#evaluationresult).

```typescript
declare class Engine {
    private config;
    readonly registry: ToolRegistry;
    private evaluators;
    private controlDefs;
    constructor(config: ResolvedConfig, options?: {
        registry?: ToolRegistry;
        rateTracker?: RateTracker;
        baselineWindow?: BaselineWindow;
        evidenceStore?: DE04StoreAdapter | null;
    });
    evaluate(action: Action): EvaluationResult;
    /** Expose evaluators for testing (e.g., to inject a broken evaluator). */
    _setEvaluator(controlId: string, evaluator: ControlEvaluator): void;
    private isPolicyGated;
}
```

## Middleware

### AncilisMiddleware

**Kind:** class &middot; **Module:** `ancilis/middleware`

MCP middleware — intercepts tool calls, evaluates them through the engine, and enforces decisions (blocked calls raise a [`BlockedToolCallError`](#blockedtoolcallerror) rather than reaching the server). It auto-registers discovered tools, scans responses for sensitive-data patterns, and records evidence. Wrap an MCP client that conforms to [`McpClientLike`](#mcpclientlike).

```typescript
declare class AncilisMiddleware {
    private _config;
    private _client;
    private _registry;
    private _engine;
    private _evaluationLog;
    private _scanResults;
    private _driftEvents;
    private _evidenceStore;
    private _issueCount;
    constructor(client: McpClientLike, options?: AncilisMiddlewareOptions);
    get config(): ResolvedConfig;
    get registry(): ToolRegistry;
    get evidenceStore(): EvidenceStore;
    get evaluationLog(): EvaluationResult[];
    get scanResults(): ScanResult[];
    get driftEvents(): DriftEvent[];
    callTool(name: string, args?: Record<string, unknown>): Promise<{
        content: Array<{
            type: string;
            text?: string;
            [key: string]: unknown;
        }>;
        [key: string]: unknown;
    }>;
    listTools(): Promise<{
        tools: Array<{
            name: string;
            description?: string;
            [key: string]: unknown;
        }>;
        [key: string]: unknown;
    }>;
    getRecommendations(): string[];
    getSummaryLine(): string;
    getLastEvaluation(): EvaluationResult | undefined;
    private extractResponseText;
}
```

```typescript
import { AncilisMiddleware } from "ancilis";

const mw = new AncilisMiddleware(client, { configPath: "ancilis.yaml" });
const result = await mw.callTool("web_search", { query: "ancilis" });
```

## Evidence

### EvidenceStore

**Kind:** class &middot; **Module:** `ancilis/evidence`

DuckDB-backed evidence store with hash chain integrity. Converts an [`EvaluationResult`](#evaluationresult) into an immutable [`EvidenceRecord`](#evidencerecord), links it into a cryptographic hash chain, and supports querying, counting, chain verification, summaries, and pruning.

```typescript
declare class EvidenceStore {
    private _db;
    private _conn;
    private _certifications;
    private _llmProvider;
    private _initialized;
    private _dbPath;
    private _inMemory;
    private _tenantId;
    constructor(config: ResolvedConfig, options?: {
        dbPath?: string;
        inMemory?: boolean;
        tenantId?: string;
    });
    get dbPath(): string;
    private ensureInitialized;
    close(): Promise<void>;
    private getLastHash;
    store(evaluation: EvaluationResult, toolName: string, outputSummary?: string | null): Promise<EvidenceRecord>;
    getRecords(filters?: {
        agentId?: string;
        toolName?: string;
        decision?: string;
        since?: string;
        sessionId?: string;
        limit?: number | null;
    }): Promise<EvidenceRecord[]>;
    count(scope?: SessionScope): Promise<number>;
    verifyChain(scope?: SessionScope): Promise<{
        valid: boolean;
        errors: string[];
    }>;
    getSummary(options?: {
        since?: string;
        sessionId?: string;
    }): Promise<Record<string, unknown>>;
    /** Execute a DDL or DML statement with no result. */
    exec(sql: string): Promise<void>;
    /** Run a parameterised query and return all rows. */
    query(sql: string, params?: unknown[]): Promise<DuckDBRow[]>;
    /** Run a parameterised DML statement (INSERT / UPDATE / DELETE). */
    run(sql: string, params?: unknown[]): Promise<void>;
    listSessions(): Promise<Array<{
        session_id: string;
        count: number;
        first_seen: string;
        last_seen: string;
    }>>;
    latestSessionId(): Promise<string | null>;
    reset(): Promise<number>;
    purgeBefore(beforeTimestamp: string): Promise<number>;
    private rowToRecord;
}
```

> The `SessionScope` parameter accepted by `count` and `verifyChain` is `{ sessionId?: string | null } | string | undefined`; `DuckDBRow` is `Record<string, unknown>`. Both are internal type aliases (not exported).

```typescript
import { loadConfig, EvidenceStore } from "ancilis";

const config = loadConfig({ raw: { agent: { name: "ancilis-agent" } } });
const store = new EvidenceStore(config, { inMemory: true });
```

## Errors & Warnings

All SDK errors extend [`AncilisError`](#anciliserror) and carry a structured error code (`E001`–`E010`), a human-readable message, an optional fix suggestion, and a documentation URL. Warnings are modeled by [`AncilisWarning`](#anciliswarning) (codes `W001`–`W003`) and are returned alongside results rather than thrown.

### AncilisError

**Kind:** class &middot; **Module:** `ancilis/errors`

Base class for all Ancilis SDK errors. Every error carries `code` (e.g. `"E001"`), an optional `suggestion` (actionable fix hint), and `docsUrl` (canonical docs page for this code). `format` renders a multi-line, colour-formatted string suitable for CLI output.

```typescript
declare class AncilisError extends Error {
    readonly code: string;
    readonly suggestion?: string;
    readonly docsUrl: string;
    constructor(code: string, message: string, suggestion?: string);
    format(colorEnabled?: boolean): string;
}
```

### AncilisWarning

**Kind:** class &middot; **Module:** `ancilis/errors`

Structured warning — not raised as an exception, returned alongside results. Carries `code` (e.g. `"W001"`), `message`, an optional `suggestion`, and `docsUrl`. `format` renders a multi-line, colour-formatted string suitable for CLI output.

```typescript
declare class AncilisWarning {
    readonly code: string;
    readonly message: string;
    readonly suggestion?: string;
    readonly docsUrl: string;
    constructor(code: string, message: string, suggestion?: string);
    toString(): string;
    format(colorEnabled?: boolean): string;
}
```

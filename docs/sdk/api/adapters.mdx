---
title: Provider Adapters
description: Observe-only adapters that translate native LLM-provider API calls (Anthropic, Azure OpenAI, Bedrock, Cloudflare, Hugging Face, and more) into Ancilis Actions, evaluations, and evidence.
---

Provider adapters (also called provider producers) observe native LLM-provider
API calls and turn them into the standardized Ancilis `Action` shape so they can
be evaluated and recorded as evidence. They cover providers such as Anthropic,
Azure OpenAI, AWS Bedrock, Cloudflare Workers AI, Hugging Face Inference, Google
Vertex AI, Replicate, and the OpenAI Assistants and Realtime APIs.

These adapters are **observe-only**: they record evidence but cannot block a
call. Each adapter accepts a plain dictionary or a typed `*Invocation`
dataclass, so the SDK stays importable without the provider's own Python package
installed. For every provider there are four exported symbols:

- a `*ActionProducer` — the main adapter class,
- a `*Adapter` — a backwards-compatible alias for the producer,
- an `*Invocation` dataclass — the raw, pre-translation envelope, and
- an `*Observation` dataclass — the resulting action, evaluation, and evidence.

All symbols on this page are exported from `ancilis.adapters`.

```python
from ancilis import load_config
from ancilis.adapters import AnthropicActionProducer, AnthropicInvocation
from ancilis.engine.engine import Engine

config = load_config()
producer = AnthropicActionProducer(config, Engine(config))

invocation = AnthropicInvocation(operation="Messages.create", model="claude-3-5-sonnet")
observation = producer.observe(invocation)
```

## Anthropic

### AnthropicActionProducer

**Kind:** class

```python
AnthropicActionProducer(config: 'ResolvedConfig', engine: 'Engine', registry: 'ToolRegistry | None' = None, evidence_store: 'EvidenceStore | None' = None) -> 'None'
```

Produces `Action` objects from native Anthropic API invocations. The adapter
accepts plain dictionaries or `AnthropicInvocation` objects so the SDK stays
importable without the `anthropic` Python package installed. Observe-only.

### AnthropicAdapter

**Kind:** class

```python
AnthropicAdapter(config: 'ResolvedConfig', engine: 'Engine', registry: 'ToolRegistry | None' = None, evidence_store: 'EvidenceStore | None' = None) -> 'None'
```

Backwards-compatible alias for [`AnthropicActionProducer`](#anthropicactionproducer).

### AnthropicInvocation

**Kind:** class

```python
AnthropicInvocation(operation: 'str', model: 'str | None' = None, request_body: 'Any' = None, response_body: 'Any' = None, stream_chunks: 'Sequence[Any] | None' = None, http_status: 'int | None' = None, request_id: 'str | None' = None, latency_ms: 'float | None' = None, headers: 'Mapping[str, Any] | None' = None, response_metadata: 'Mapping[str, Any] | None' = None, agent_id: 'str | None' = None, auth_mode: 'str | None' = None, base_url: 'str | None' = None) -> None
```

Raw Anthropic API invocation before translation to an Action.

### AnthropicObservation

**Kind:** class

```python
AnthropicObservation(action: 'Action', evaluation: 'EvaluationResult', evidence: 'EvidenceRecord') -> None
```

Action, evaluation, and evidence record for an observed Anthropic call.

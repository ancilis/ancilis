Reference for the supporting TypeScript surface of the Ancilis SDK: test utilities, dependency vulnerability scanning, anonymous usage telemetry, finding importers, and activation/overlay helpers.

Every symbol on this page is a top-level export of the `ancilis` package. Signatures are copied verbatim from the compiled type declarations.

```typescript
import {
  MockEvidenceStore,
  scanDependencies,
  SarifImporter,
  ActivationResolver,
} from "ancilis";
```

## Testing

Mocks, assertion helpers, and pre-built scenarios for writing unit tests against compliance requirements without hitting the platform API or writing to disk.

### MockEvidenceStore

**Kind:** class

In-memory evidence store for testing. Drop-in replacement for `EvidenceStore` that uses DuckDB `:memory:` mode — no filesystem writes, no DuckDB files. Safe to use in any test environment.

```typescript
class MockEvidenceStore {
  constructor(agentName?: string, mode?: "audit" | "enforce", overlay?: string);
  /** Store an evaluation result. */
  store(evaluation: EvaluationResult, toolName?: string): Promise<EvidenceRecord>;
  /** Count stored records. */
  count(): Promise<number>;
  /** Get summary of stored records. */
  getSummary(): Promise<Record<string, unknown>>;
  /** Verify the hash chain integrity. */
  verifyChain(): Promise<{ valid: boolean; errors: string[] }>;
  /** Reset all evidence records. */
  reset(): Promise<number>;
  /** Close the underlying DuckDB connection. */
  close(): Promise<void>;
}
```

```typescript
const store = new MockEvidenceStore();
await store.store(evaluation, "my_tool");
expect(store.count()).resolves.toBe(1);
await store.close();
```

### FakeProducer

**Kind:** class

Injects synthetic evidence without running real agent code. Implements the `ActionProducer` protocol. Use in tests to produce `Action` objects with controlled data, without any real tool connectivity.

```typescript
class FakeProducer implements ActionProducer {
  constructor(producerName?: string, agentId?: string, agentOwner?: string | null);
  get producerType(): ProducerType;
  get producerVersion(): string;
  /** Record a synthetic evidence item. */
  emit(key: string, value: unknown): void;
  /** All emitted evidence items (read-only copy). */
  get emittedData(): Record<string, unknown>;
  /** Reset all emitted items. */
  clear(): void;
  /** Create an Action for engine evaluation. */
  makeAction(options?: {
    toolName?: string;
    parameters?: Record<string, unknown>;
    sessionId?: string | null;
    dataClassifications?: string[];
    sourceType?: string;
  }): Action;
  translate(rawInvocation: unknown): Action;
  computeToolHash(toolIdentifier: unknown): string;
  registerTools(registry: ToolRegistry): string[];
}
```

```typescript
const producer = new FakeProducer("identity");
producer.emit("user.id", "alice");
producer.emit("session.start", { timestamp: "2026-04-11T10:00:00Z" });

const action = producer.makeAction();
const result = engine.evaluate(action);
```

### ComplianceScanResult

**Kind:** class

Exported at the top level as `ComplianceScanResult` (the underlying class is `ScanResult` in `ancilis/testing`). Wraps one or more `EvaluationResult` objects with a computed posture score. Returned by `ComplianceScenarios` factory methods and accepted by the compliance assertion helpers.

```typescript
class ScanResult {
  readonly evaluations: EvaluationResult[];
  constructor(evaluations: EvaluationResult[]);
  static fromSingle(evaluation: EvaluationResult): ScanResult;
  /** Pass rate across all scored controls in all evaluations. SKIP excluded from denominator. */
  get score(): number;
  /** Return the ControlResult for the given controlId (latest evaluation). */
  getControlResult(controlId: string): ControlResult | undefined;
  /** Decision from the most recent evaluation. */
  decision(): string;
  toString(): string;
}
```

### ComplianceScenarios

**Kind:** class

Factory for pre-built compliance test scenarios. All scenarios work fully offline — no platform API, no DuckDB file. Each static method returns a `ScanResult` (`ComplianceScanResult`).

```typescript
class ComplianceScenarios {
  /**
   * All controls passing for a financial services overlay context.
   * Simulates a well-configured agent with identity, scope, provenance,
   * and exposure controls all PASS. Active overlays: financial.
   */
  static financialCompliant(): ScanResult;
  /**
   * PR-01 fails — agent identity is missing. All other controls pass.
   */
  static missingIdentity(): ScanResult;
  /**
   * Bare minimum passing scenario — only PR-01 scored, rest skipped.
   */
  static minimalViable(): ScanResult;
  /**
   * All controls failing — useful for testing assertion error messages.
   */
  static allFailing(): ScanResult;
  /**
   * Enforce mode with a failing control — decision is BLOCK.
   */
  static enforceBlocked(): ScanResult;
}
```

```typescript
const scenario = ComplianceScenarios.financialCompliant();
assertControlPasses(scenario, "PR-01");
assertPostureAbove(scenario, 0.80);
```

## Dependencies

Two complementary dependency-scanning surfaces are exported at the top level: a class-based API (`DependencyScanner`, `ManifestDetector`, `OSVClient`) that produces `EvaluationResult[]`, and a functional API (`scanDependencies`, `detectDependencies`, `buildSbom`, `queryOsvBatch`) that returns plain result objects and a CycloneDX SBOM.

}

### scanDependencies

**Kind:** function

Scan a project directory for npm dependency vulnerabilities. Detects the first lockfile found (pnpm > yarn > npm), generates a CycloneDX SBOM in-memory, and queries OSV.dev for known CVEs.

- `projectDir` — Absolute path to the project root. Defaults to `process.cwd()`.
- Returns a `DependencyScanResult` with findings and SBOM.

```typescript
function scanDependencies(projectDir?: string): Promise<DependencyScanResult>;
```

```typescript
import { scanDependencies } from "ancilis";

const result = await scanDependencies(process.cwd());
console.log(`Found ${result.vulnerabilities.length} vulnerabilities`);
```

## Activation

The activation resolver reads config, handles both the data-handling and certification paths, and produces a unified `ActivationSpec`. The advisory generator turns detected patterns into classification recommendations and certification upgrade advisories.

### ActivationResolver

**Kind:** class

Activation resolver. Reads config and produces a unified `ActivationSpec`.

```typescript
class ActivationResolver {
  constructor();
  resolve(options?: {
    dataHandling?: string[];
    certificationTargets?: string[];
  }): ActivationSpec;
}
```
